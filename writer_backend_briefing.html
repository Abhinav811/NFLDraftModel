Writer’s backend briefing

Internal notes for a casual-but-accurate 2026 article. Not copy. Numbers below are from the live code and the last walk-forward (trained through 2025, board for 2026). Date of this dump: 20 Aug 2026.

What you are writing about: a 12-team full-PPR ranking model whose job is not “nail every player’s point total.” It is “rank drafted players relative to ADP / Vegas, and paint a name green or red only when the gap is large and there is a football reason.”

Live board: https://abhinav811.github.io/NFLDraftModel/ · GitHub: Abhinav811/NFLDraftModel · Pages from main / docs.

Do not claim in the article

  • That this is a betting model, or that VFP is +EV on props.
  • That point MAE (~55 PPR) is “accurate crystal ball” — that error is normal for season-long fantasy; the claim is ranking lift vs ADP.
  • That the model beats ADP every year. 2021 was a tiny loss (−0.005 Spearman); 2024 was a tie (+0.001). Mean lift ~+0.019.
  • That every ADP disagreement is a steal. Close-to-ADP names are a coin flip. Flags need ±5 position ranks and ±12 PPR and a confirmer.
  • That Half PPR is a second trained model. It is full PPR minus 0.5 × projected receptions.
  • That midseason is a separate product. Same board; live team + remaining SOS move names in place. Steal/fade flags stay frozen.

1. One-sentence architecture

For each skill player (QB/RB/WR/TE) in season t, build a market number m (Vegas fantasy points if a prop exists, else an ADP-implied points curve), mix in a tenure-weighted prior (production, situation, physical, aging), then add a small gradient-boosted residual that tries to predict how last year’s m was wrong. Tune how much residual to trust (λ) on ranking correlation, not on how many names turn green.

ŷ  =  market_or_blend  +  λ_tenure · residual  +  k · rank_lift
     then a little extra pull toward the prior for rookies without a prop

Walk-forward: train only on seasons < t, score t. Never use 2026 outcomes (they don’t exist). Historical m is ADP because there is no archive of player-level season props.

2. Pipeline (what actually runs)

  1. python3 scripts/run_pipeline.py — download nflverse + ADP + props, build data/processed/player_panel.parquet (not published), walk-forward backtest, fit 2026, write rankings CSVs + methods HTML + rebuild docs/index.html.
  2. python3 scripts/refresh_board.py — no retrain. Re-rank the saved 2026 CSV with live Sleeper injuries/teams and remaining SOS. Used by GitHub Action daily 14:00 UTC.
  3. Push docs/index.html (and figures) to main for Pages.

Processed parquet is gitignored on purpose. The hosted page is a static HTML blob of ~192 ADP-drafted names.

4. Scoring (what “points” means)

pass yard  0.04     rush/rec yard  0.10     reception  1.00
pass TD    4.00     rush/rec TD    6.00     INT / fum  −2.00

That is full PPR. Half PPR on the board is the same ŷ minus ½ × projected receptions (prop receptions if present, else last year’s, else a position catch-rate × targets). Not a re-fit.

Games: 16 through 2020, 17 from 2021 on (including 2026).

5. The market layer — what “ADP” and “Vegas” actually are

5.1 Vegas Fantasy Points (VFP) — 2026 only

Posted over/under L is treated as a median. American odds → implied p_over / p_under, vig-stripped to a fair over probability, then a damped shift of the line:

p = |o|/(|o|+100) if o<0 else 100/(o+100)
p_fair = p_over / (p_over + p_under)
z = clip( Φ⁻¹(p_fair), −1.5, 1.5 )
E[X] = L + 0.35 · σ_market · z
VFP = Σ E[X_k] · scoring_k

σ scales (so juice cannot yank a total several σ): pass yd 450, rush yd 180, rec yd 160, rec 12, pass TD 4.5, rush TD 2.8, rec TD 2.4, INT 2.2, fum 1.2. Used as m only if vfp_markets ≥ 1.

Casual angle: books are better at volume than a public model. The model is not trying to out-Vegas passing yards. It is trying to notice aging, vacated touches assigned to a person, TD luck vs role, cliffs, etc.

5.2 ADP-implied points (historical m, and 2026 fallback)

By position, OLS: m_ADP = β0 + β1 · log(ADP) fit on historical (ADP, actual PPR). Two WRs five picks apart can be 40 PPR apart. This is a points market, not “they’re next to each other on a cheat sheet.”

FFC 12-team PPR ADP. Sample weights in the trees: everyone 1×; ADP ≤150 gets 4×; ≤72 gets 5.5×; steal band 18–132 gets another ×1.2. The model is trained to care about draftable names, not UDFA dart throws.

6. Features a yardage prop cannot see

These feed the prior and/or the trees. Trees see ~100 columns plus position_code and tenure_code. Team-context columns are pre-shrunk so O-line/SOS cannot dominate usage: ×0.35 for OL/scheme/pace, ×0.40 for SOS / indoor / implied totals.

6.1 Age

Age = days from birth to Sept 1 of season t / 365.25. Peaks: QB 30, RB 26.5, WR 28, TE 28.5.

α_age = clip( 1 − λ_pos · [age − peak]₊² ,  0.35,  1.05 )

λ is fit on players already past the peak with last-year PPR > 50. Defaults if thin: QB 0.012, RB 0.035, WR 0.018, TE 0.016. RBs fall off harder because the data said so.

No market → zero w_m and renormalize. Situation multipliers (on top of OL / vacated / SOS / depth): cliff ×0.90, breakout ×1.06, team change ×0.97, role expand ×1.04, chronic injury ×0.96. Injury-bounce is still a tree feature; it is not a situation multiplier or a steal confirmer (it was anti-predictive).

6.3 Depth and vacated usage

Depth snapshot: historical week-1 REG (or last snapshot before Sept 8); 2026 = latest chart. Rank 1/2/3 weights 0.52 / 0.28 / 0.13. Vacated team share is split onto people by prior share + depth (rookies depth-only). player_vacated_boost = leftover targets for WR/TE, leftover carries for RB.

6.4 Red zone and TD luck (this is the fade “TD luck (over)”)

From PBP, dropping kneels, spikes, penalties, 2-pt. Inside-5 carry: yardline_100 ≤ 5. Inside-10 target: ≤ 10. End-zone target: air_yards ≥ yardline_100 − 0.5 and yardline_100 ≤ 20.

HV-RZ = 1.4·carries_in5 + 1.0·targets_in10 + 1.6·ez_targets
rec_TD_luck  = rec TDs  − (0.20·targets_in10 + 0.28·ez_targets)
rush_TD_luck = rush TDs −  0.42·carries_in5
td_luck      = rec_TD_luck + rush_TD_luck

Positive = scored more TDs than the role implied (binge). Negative = under-scored relative to looks. Fade confirmer: td_luck ≥ 2.0. Steal confirmer: td_luck ≤ −1. TD luck alone never paints a name; it only confirms a gap that is already ≥5 ranks and ≥12 PPR.

7. How the trees are actually weighted

Four HistGradientBoosting regressors, sklearn, random_state=7:

TreeTargetDepth / iter / leaf
pointsactual PPRdepth 3, 280 iter, min leaf 22, lr 0.05, L2 0.55
global residualactual − market_fpsame, 220 iter; output clipped ±60
position residualsame, per pos if n≥120180 iter, leaf 18; mixed 55% local + 45% global
rank liftADP pos rank − actual pos rankdepth 2, 200 iter; clipped ±18

Final mix when a market exists:

ŷ = base + λ_tenure · residual + clip(k · lift, −22, 22)
λ_tenure = λ·1.15 rookies,  ·1.05 years 1–2,  ·0.85 years ≥7,  else λ
base = VFP if vfp_markets≥1 else ADP-implied points (else blend, else last PPR, else 80)

No market: 0.6·points_tree + 0.4·blend.

Rookie gravity toward prior: extra 40% / 18% / 5% blend for years 0 / 1 / ≥2, but if they have a real VFP that extra is capped at 8% (don’t drag a posted rookie 40% off the books toward a combine prior).

λ and k are not hand-set. Grid λ ∈ {0.25, 0.40, 0.55, 0.75, 1.00}, k ∈ {0, 1.5}. Fit trees on seasons before the last training year; pick the pair that maximizes Spearman on ADP-drafted players in that last year. Maximize ρ, not steal count. Last 2026 fit used k=0 (rank-lift tree off). λ in backtests ranged 0.25 (2021) to 1.0 (2024).

Casual angle: turning the residual up until more names go green is how you lose to ADP. 2024’s tuner chose λ=1.0 and still only tied ADP. The usable edge is disagreement, not “trust the trees more.”

8. Steal / fade (the green and red pills)

Computed on positional ranks among ADP-drafted players, not overall VORP pick. Hover “i” lists up to three confirming phrases.

Steal if all of:

  1. ADP ∈ [18, 132] (skip 1.01s and dart throws)
  2. model position rank ≤ ADP position rank − 5
  3. ŷ − m ≥ 12 PPR
  4. at least one of: role expand, sophomore leap, pass_catch_rb ≥ 0.08, td_luck ≤ −1, new_starter_vacated ≥ 6

Fade if (2)–(3) flip sign and at least one of: workload cliff, chronic injury, td_luck ≥ 2.0, overproduction ≥ 0.55, eff_index ≥ 1.4.

Early-round fades (ADP < 18): need fade_why and either ≥10 PPR below m, or a workload cliff with edge ≤ +5. You do not fade a 1.01 because a tree twitched.

Walk-forward flag hit (stricter ≥4 actual rank gain metric in code): 10 steals, 60% hit, mean +9.5 ranks; 47 fades, 70% hit. Re-ranking inside the ADP pool, steal flags were closer to 80% beating ADP rank. Either way: small n on steals; the bigger published edge is any ≥5-rank cheap call, not only painted names.

Cheap-call (not flag) walk-forward, ADP pool: ≥5 ranks cheaper beat ADP rank 76% (68–93% every year). ≥8 cheaper: 81%, mean +12.5 ranks. Mid-round ADP 36–96: historically model-cheap names scored more actual PPR than model-expensive names at the same cost (old figure ~177 vs 154).

9. How the hosted big board is ordered

This is the thing that broke when QBs flooded round 1.

  • Positional tabs: sort by projected PPR (or rest-of-season PPR in season). QB1 = most points at QB. Correct.
  • Full board: sort by VORP = ŷ − replacement starter in a 12-team 1QB league. Roster is 2 RB, 2 WR, 1 FLEX (plus 1 QB, 1 TE). Replacement ranks: QB12, RB30, WR30, TE12 (12 flex spots split evenly: 24 starters + 6 flex at each of RB and WR). Same-position VORP order = points order. Across positions, elite RBs jump QBs because QB12 still scores ~270 PPR and RB30 does not. (An earlier 3-WR / WR36 version overstated how many WRs you have to start.)
  • vs ADP on the full board: overall ADP rank − overall pick (CMC pick 2 vs ADP ~7 → +5). On positional tabs: ADP position rank − model position rank (CMC RB2 vs ADP RB3 → +1).
  • Steal/fade pills still use the positional ±5 / ±12 rule + confirmer, not the overall vs number. Josh Allen can be +20 overall vs ADP and still be “fair” if he is QB1 vs ADP QB1.

Round headers: pick 1–12 = round 1, etc. 12-team snake. Early/mid/late within a round is picks 1–4 / 5–8 / 9–12 of that round.

10. Live overlay (does not retrain)

ros_fp = model_fp
       × (games left / scheduled)
       × (1 + 0.08 · SOS_remaining) / (1 + 0.08 · SOS_full)
       × indoor remaining/full for WR/QB

SOS is last year’s opponent defensive EPA on this year’s leftover opponents. After ~6 weeks of league games, blend in current-year YTD defense. Live team prefers Sleeper. Designations: IR / PUP / Q / O / D / SUS. Steal/fade labels stay frozen when names move. Daily Action: cron 0 14 * * * runs refresh_board.py and commits docs/index.html if it changed.

Toggles on the page: Full/Half PPR, Full/Positional, Start/Exit Draft (browser localStorage only). There is no separate midseason mode.

12. Example you already asked about (CMC vs Bijan)

Overall pick is VORP; both RBs share the same replacement line, so this is just 292 vs 286 PPR (~6 points). Vegas and ADP have Bijan first (VFP 308 vs 287; ADP 1.7 vs 6.5). The prior/blend also has Bijan higher (342 vs 321). The residual trees flip them because CMC’s 417 PPR / 311 carries / 102 catches last year outweigh age-30 + workload cliff enough to land near his VFP, while Bijan is faded vs a 308 book / 1.01 ADP after td_luck 5.7 and eff_index 2.6. Neither is a steal/fade. Safe casual line: “six points, coin flip, the model is a little more scared of paying 1.01 for a TD binge than of a 30-year-old who just put up 417.”
